# 医学主线与baseline完整结果总结（2026-10-26）

**汇报结论：主线已体现“可保留器官身份、相对普通U-Net及部分外部方法有收益”的价值；现有证据尚不足以证明“多专家机制全面领先”或“超过所有baseline”。** 最有说服力的结果是Region的器官曝光校正，以及Task-ID的弱负载均衡。Q06/Q07补齐了机制对照，也暴露出路由更均衡与分割更好并不等价。

本报告汇总已有正式产物，不新增训练或按测试集重新选参。Q06于10月25日06:19完成；Q07经主机重启断点恢复，于10月26日13:22完成全部训练、评价和成本测量。未来新实验仅seed42；已完成三种子实验保留原结果。

- 本测试划分已经在历史研究中反复查看；阶段之间挑最高测试分的版本只能作回顾性分析，最终模型仍需按验证规则冻结，并以独立新数据验证。腹部是模拟超声，当前不能宣称真实临床腹部泛化。

## 9. 能否体现我们的主线：可用于汇报的表述

**可以体现，但当前应定位为具有竞争力的多域、逐器官分割框架，并坦诚多专家增益仍有限。**

1. **功能价值有依据。** Region保留图像条件、16结构输出和一次前向的使用方式；Task-ID可按结构查询；纯单通道只预测前景并集。器官身份是可验证的功能差异，单靠功能差异还不能证明相对其他条件式方法的新颖性。
2. **方法收益有阶段证据。** Region的曝光校正、Task-ID的弱均衡已有三种子配对结果；相对单通道和部分外部baseline存在实测收益。应报清楚对应版本和指标。
3. **性能与容量存在价值取舍。** 约13M参数的主线在共同并集任务上优于本次Lanzhou、SMART、MOFO复现，且靠近更大的AImageLab；阳性并集仍未胜出。“有竞争力、参数更少”比“全面SOTA”符合现有证据。
4. **多专家因果证据仍弱。** Q06改善路由却没有明确best分割收益，Q07的9专家相对无专家结构提升极小且成本增加；不可把“每个专家必然学会对应器官”作为已有结论。

建议汇报原话：

> 我们建立了九数据域、16结构的统一分割框架，并完成普通单通道U-Net、外部方法和多阶段配对消融。器官监督曝光校正及任务路由弱均衡带来了可复核的局部收益。主线用约13M参数，在共同前景并集任务上优于部分外部复现，阳性分割仍落后于AImageLab。机制对照表明，路由分散本身并不保证性能，多专家相对同条件共享网络的收益目前有限；腹部小器官漏检仍是主要瓶颈。

## 10. 下一步应补的证据

- 依据训练／验证选择一条最终方法路线，固定损失、选点、数据与输出，再以独立新测试数据评价；不把本报告每列的测试最优值拼为一个模型。
- 优先检查小器官阳性曝光、空间细节保留、身份错分和完全空预测，联合DSC、距离、误检／漏检确定是否解决腹部问题。
- 若继续强调MoE，需在当前单seed政策下补容量匹配的同条件U-Net，以及同硬件端到端成本；当前Q07已经提示共享条件解码器是必须认真对待的强对照。
- 外部方法共同主表继续用并集；逐器官优越性只对拥有相同输出能力、相同协议的对手讨论。UniverSeg保持延期，不计作完成baseline。

以上是基于已完成结果的建议，本次没有新增训练队列。
