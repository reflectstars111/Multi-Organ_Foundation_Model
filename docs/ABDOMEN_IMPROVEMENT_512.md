公平对照固定为 paper5 的16个结构、`ct7_2` 腹部源划分、`trainmore_v6`、512×512输入。腹部训练集477张图，肝/肾/血管/胆囊/脾的阳性图分别为341/236/153/129/122张。验证集CT3有66张、CT4有90张；血管阳性分别为9和30张。早期50轮seed42训练中，三种模型的血管Dice曾约为0.27–0.30，后来趋向空预测；这不是全部80轮或Q01实验的当前结果。肾空标签图像也有误检，因此候选必须同时报告前景Dice、空标签误检率/面积和阳性零重叠率。

这里的公平对照 `shared` 是 16 通道**多头共享 U-Net**；用户后来明确提出的单通道前景并集 U-Net 按[另一协议](SINGLE_CHANNEL_UNION_512.md)训练和评价，两者的 Dice 口径不同。

## 已完成的验证集后处理筛查

使用 Region seed=42 公平对照的验证选优检查点（epoch 39），只对腹部 156 张验证图像进行推理。修正版测试了 80 组阈值和连通域规则（最低阈值 0.05），采用同一套 Dice、漏检和误检护栏。没有规则通过另一 CT 源的检查；血管在最低阈值下仍完全不预测前景。肾的一种规则使 CT3 的空标签误检面积下降，但在 CT4 多产生一个阳性零重叠病例，因此未采用。结果见 `runs/abdomen_postprocess_512_20260930_v2/screen.json`。

第一版连通域代码曾在筛选连通域前读取真值中的 ignore 区域，实际推理时无法这样做。其输出已在 `runs/abdomen_postprocess_512_20260930/superseded.json` 标记作废，原源码快照已保留。修正版先在整张预测图上选连通域，统计指标时才屏蔽 ignore 像素。CT3/CT4 都参与过原模型检查点选择，因此本筛查只是探索性验证，不能视作独立外部验证。

## 已完成的三种子配对微调（历史协议）

这批六组×三种子的 8 轮微调已完成；12/18 次最终选择微调前检查点，没有候选通过预设条件。下面保留原设计及监测入口供追溯；新 Q01 是独立的从头训练实验，不能将本批短程微调无收益解释为从头训练加权也无效。

基于公平对照中每个 seed 的 Region 最佳检查点，重置 AdamW，六个实验组各训练 8 轮。每轮每域抽 128 张图，总计 1152 张；base16、Top-1、batch4、学习率 `1e-4`、512×512。各组与同 seed 对照从相同参数开始；除采样组外，训练图像抽样顺序相同。采样组只改变腹部域内、训练集标签确定的血管或脾阳性图抽样权重，仍保持每域 128 张图。所有实验都只用训练集更新参数、验证集选择和比较模型；训练/验证图像与掩膜内容哈希写入计划，测试图像与掩膜不参与。

| 实验组 | 相对于微调对照的唯一变化 |
|---|---|
| `control` | 原损失与均匀腹部抽样 |
| `empty_0p002` | 空标签 top 1% 像素惩罚权重 0.002 |
| `empty_0p01` | 同项权重 0.01 |
| `rare_positive_x2` | 血管、脾阳性通道损失权重 2 |
| `abdomen_positive_sampling_x3` | 含血管或脾阳性的腹部训练图抽样权重 3 |
| `rare_positive_x2_empty_0p002` | 阳性通道权重 2 与空标签惩罚 0.002 组合 |

预设筛选先约束总体前景Dice、腹部及肾空标签误检面积、腹部阳性零重叠和肾前景Dice，再要求候选相对三种子配对对照提高腹部五结构前景宏Dice；全部实验固定0.5阈值。完整数值边界已保存到`plan.json`；五个候选组均未同时过关，最终记为“未选中”。这些微调在50轮正式对照生成完整测试汇总后独立执行，原对照源码和产物保留。
