## 2. 模型名称和实验对象

| 名称 | 输入／输出 | 共享方式及比较边界 |
|---|---|---|
| 共享 U-Net（单通道） | 图像→1个前景并集通道 | 用户要求的纯普通 U-Net；不输入域或任务ID，不输出器官身份 |
| 16通道 U-Net（附加对照），代码名 `shared` | 图像→16个结构通道 | 所有数据域共同更新同一套编码器和解码器；仅末层区分结构 |
| Task-ID MoE，`task_id` | 图像＋已标注任务ID→该结构二值结果 | 同一张多器官图展开为多个查询；需要任务条件，计算量与另两种不同 |
| Region MoE，`region` | 图像→16个结构通道 | 依据预测软区域特征选择专家，前向不输入任务ID |
| 九个独立 U-Net | 按已知数据域选择一套网络 | 九套独立参数；目前只有历史配置结果，尚无同一80轮协议的完整三种子对照 |

80轮 base24 的参数量：16通道U-Net **4,418,824**、Task-ID **13,257,949**、Region **13,311,644**；共享U-Net（单通道）**4,418,449**。统一图像预算不代表统一参数量、FLOPs、条件信息或运行时间。GPU与其他任务共享，日志耗时不能直接作为架构效率排名。

`TASKS` 中21个槽位是兼容编号，历史完整区域目标有19类，当前 `paper5` 为16类。不要把槽位数、输出通道数、数据域数或专家数混为一谈。[架构和标签约定](../unet_moe/README.md)

## 8. 阅读结果时必须区分的口径

| 名称 | 实际含义 |
|---|---|
| `macro_positive_dice` | 每结构只统计真值阳性图，再对结构等权平均；当前paper5为16结构，历史all8为19结构 |
| `macro_all_dice`／旧Task-ID的`macro_dice` | 包含空标签图，空真值＋空预测计1，与阳性Dice不可混比 |
| `abdomen_macro_positive_dice` | 腹部五类阳性Dice等权平均，不是腹部并集Dice |
| 9域阳性并集宏Dice | 每图合并指定有效前景，先域内阳性图平均，再9域等权 |
| 空标签误检率 | 空真值图中出现任意预测前景的图像比例 |
| 空标签误检面积 | 有效标注区域内错误前景像素的面积或比例，不能替换成图像误检率 |
| 阳性零重叠率 | 真值阳性图中交集为0的比例，包含预测为空及预测完全错位 |
| 阳性完全漏检率 | 真值阳性图上完全不输出前景的比例，是零重叠情形的一部分 |
| val／test／跨种子SD | 分别代表选优数据、冻结后的评价数据、训练随机性的离散程度；均不等于独立患者泛化置信区间 |

测试集已在历史分析中被查看；新的test开关和延后评价流程不能把它恢复为“从未接触的外部测试集”。尚无已完成的腹部五折产物、真实腹部外部验证，或新80轮九独立U-Net三种子结果。
