- DSC为百分数；HD95与ASSD单位为评价网格pixel。先每结构/域对图像平均，再等权宏平均；16结构和9域并集的分母不同，不能互比数值高低。
- `positive_surface_defined`只按真值筛选可观测边界，保留所有漏检。正式16结构主表覆盖 **2501/2501** 个阳性图像×结构记录；并集覆盖 **1601/1603** 张阳性图，统一排除2张AUL真值无可观测边界的图。因此并集DSC与旧`positive`表略有差别。原完整`positive`仍保留，距离无定义时为NA。
- 单侧为空时DSC=0，HD95=ASSD=**722.6631 pixel**（512网格对角线）；两侧为空时100/0/0。距离差异包括整器官漏检惩罚，不只反映成功检出后的边界精细度。
- 单通道按并集训练和选优；结构模型按结构监督和选优、再合并已标注通道评价并集。因此共同并集表比较下游任务表现，不能称为条件信息、训练目标和总计算完全相同的纯架构消融。

原实验诊断中，Task-ID B相对A的空标签误检宏平均从81.32%降到16.44%，阳性整结构漏检宏平均从1.55%升到9.22%；血管空预测漏检从15.45%升到48.57%。误检和漏检分母不同，不能相减当作净收益。16通道U-Net C则改善结构与腹部DSC和距离，但空标签误检宏平均从45.04%升到58.30%，也存在取舍。

这里空标签误检指真值为空、预测至少1个有效前景像素；先在有空标签的6结构（乳腺及腹部五类）内计算，再等权宏平均，最后平均三种子，不是对763条空标签记录求微平均。阳性整结构漏检指预测完全为空，先对16结构分别计算再等权平均；它不同于“预测与真值零交集”。血管阳性分母为每seed151张。B相对A的腹部DSC在**9/9个同架构同seed配对**均提高，但这不代表全部器官或距离指标也提高。

## 7. 当前可以汇报的结论与下一步

1. **流程已闭环到Q04正式训练。** Q01/Q03全矩阵和439项三指标补评完成；HC18全部按用户要求评价填充区域，4项旧模型例外保留目标修订说明，Q04不再被补评阻塞。
2. **已证明的改进是有条件的。** Region B有较清晰的DSC收益和并集三指标收益；Task-ID B显示“并集进步、结构漏检退化”并存，必须同时报告。仅靠总体DSC选优仍可能接受器官失效。
3. **Q03不支持直接使用分域BN。** 共享BN可作为进一步研究方向，但存在脾下降与误检增加，尚未证明与器官加权叠加有效。
4. **下一项已有执行计划是Q04，其后Q02。** Q04还有13项主训练待完成（含正在跑的2项）、2项MOFO先验和15项测试；Q02为4组预检、12项训练和12项测试。没有已完成的Q04测试性能或Q02收益证据。
5. **证据边界仍需补齐。** 当前三种子使用同一固定划分，未完成腹部交叉验证、真实腹部超声外部测试或匹配80轮协议的九独立U-Net；历史test已被分析，不能宣称完全未触碰测试集。不能把相关机制解释、单次探针路由集中或均值差写成已经证明的因果机制/统计显著性。
