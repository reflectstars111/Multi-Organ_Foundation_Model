- 肝脏空真值测试图 66 张中，65 张有前景预测（98.48%），这些误报均超过 16 像素，误报图的面积中位数为 4246 像素；全部空图有效像素上的 FP 比例为 5.15%。这不是单像素噪声导致的高图像误报率。

- 449×464→512 缩放未造成腹部器官阳性样本消失，约 30% ignore 区域已正确屏蔽。五个腹部通道在四层 Top-1 中均选择专家 8；本诊断不支持把主要错误简单归于选错专家。
- 腹部图的 11 个未标注非腹部通道仍有大量激活。由于这些通道真值为 -1，不能据此计为已确认误报，也不能直接改成背景监督；masked Dice 没有验证全通道自动输出的可靠性。

新入口的 `--empty-weight` 默认 0，非零值只为已标注且有效区真值为空的腹部通道增加困难负像素 BCE；低权重仍待验证，也不处理未标注通道激活。新的模型和损失选择仍须依靠 train/val，而不是按这次 test 诊断反复筛选。

## 可复现性审查

1. **划分与训练 seed 以前耦合。**旧入口 seed42→43 时，在 ct7_2/trainmore_v6 下 test 从 1618 图变成 1696 图，交集只有 1007 图。新入口分离 `--split-seed` 与 `--seeds`；后续对照必须检查记录摘要和每集合身份。
2. **旧续训不等于完全重现。**旧区域/普通基线 checkpoint 不含完整 RNG；区域随机采样模式中断后可改变轨迹。旧 task-ID 只存 PyTorch RNG。新入口记录完整 RNG；同平台的短程续训检查仍不等于跨 CUDA/PyTorch 版本逐位一致。
3. **记录哈希不是文件内容哈希。**旧 SHA 包含绝对路径，迁移会变化；跨机器应核对相对路径语义键及迁移记录。JSON 记录未变不能排除图像或 mask 原位被修改。
4. **聚合方式必须相同。**阳性/含空 Dice、19/16 类、原图/缩放网格、图像/患者/CT 等权指标须分别标明。当前历史 JSON 无逐图完整预测，不能仅靠宏平均补出配对置信区间或边界指标。
5. **实际来源隔离有限。**CAMUS 按患者、腹部按模拟 CT、HC18 按检查编号；其他数据集未知患者关系、跨数据集重复等尚未完全排除。CT 级结果只有 4 个测试来源，图像数量不能替代独立来源数量。

运行配置、依赖环境、代码版本、采样预算和完成状态应与新产物共同保存。当前以实际完成的 JSON/epoch 记录为准，未完成的比较不预设任何模型排名。
