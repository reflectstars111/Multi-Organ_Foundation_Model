## 3. Q02／Q05 完成后的验收

### 检查点、性能与错误类型

- [ ] 核验每阶段 12 项训练完整达到 80 轮，数据／协议／源码及初始化指纹匹配，检查点和逐轮历史一致。
- [ ] 并列报告原规则的 **best、固定 epoch80 的 last、guardrail best**。没有检查点通过护栏时写“无候选”，不得用普通 best 填补；不得按测试成绩在三种检查点之间重新挑选。
- [ ] 逐 seed 给出 `auxiliary−control` 或 `refined−control`，再汇总三个种子的均值与样本标准差。完整保留逐器官、逐域和腹部来源结果。
- [ ] 同时报结构评价与共同的前景并集评价，指标为 **DSC (%)、HD95 (pixel)、ASSD (pixel)**。报告阳性和全部样本，并分别说明表面可定义子集及分母。
- [ ] 保留空预测；单边为空按 `hypot(511,511)=722.6631 pixel` 惩罚，双空 DSC=100、距离=0。无可观测真值表面的样本按既定规则标记未定义，不伪造零距离。
- [ ] 逐器官显示阳性完全空预测、零交集、空标签误检率与误检面积。完整漏检与零交集不是同一指标；结构级与并集级分母也不得混用。

旧护栏原样保留：腹部每器官阳性 DSC 至少 10%、血管至少 20%、腹部五结构宏 DSC 至少 40%，阳性零交集率不超过 50%，空标签误检面积比例不超过 2%，并要求腹部五器官均有指标。具体聚合遵循冻结实现，不能把“误检面积比例”替换成“误检图像率”。已有护栏较宽松，通过并不等于临床可用，也不自动意味着候选优于对照。

### 路由和因果解释

- [ ] 对 epoch0/1/10/20/40/60/80 的完整验证诊断，分四层统计专家活动数、最大选择份额、softmax 熵和 top1 概率，并保留域×专家、器官×专家表。
- [ ] Region 总体路由计数包含每图全部 16 个 proposal；另看已标注器官和阳性器官，避免把大量空区域的专家集中误当成所有器官均无分工。
- [ ] 联合 proposal 质量、router／专家梯度及专家残差关闭诊断解释结果。关闭已训练模型的专家残差只能说明模型依赖该路径，不能替代从头训练无专家对照。
- [ ] 单种子进步只称初步信号。专家更均衡本身不是目标；若 DSC 上升而漏检、距离或特定器官退化，应明确写成取舍。

Q02 seed42 已知风险来自 [Region epoch80 诊断](/ssd1/data/Multi-Organ_Foundation_Model/runs/q02_routing_80_512_20261013/auxiliary/region/seed_42/diagnostics/epoch_080.json)：最细层 16112 次总体路由全部选 expert0。该结论仅针对该层和这一种子；它是继续审查的理由，不是预先判定 Q05 无效。

## 4. Q06：完整 Q05 之后才冻结的 Region 路由配对

**要回答的问题：**在同样的区域监督、条件表达和预算下，抑制持续的单专家集中能否改善逐器官分割，而不仅使路由直方图更均匀？

先检查 Q05 三种子的完整验证诊断。将“refined 组至少 2/3 个种子在 epoch60 和 epoch80 的最细层均严格只有一个活动专家（`active_experts == 1`）”作为**后续审查触发条件**，并联合该层阳性器官路由、梯度和预测表现判断是否值得实验。它对应已观察到的严格独占，不另造 95%／99% 等近似阈值。四层的最大专家份额和活动数仍全部报告，其他层或接近独占的情况进入问题清单，不自动触发；单看总体独占也不会自动发起训练。

这里的2/3种子指Q05已有的验证证据，不要求新增Q06三种子训练。Q06若触发，仅执行下表seed42两项。

若触发且存在任务相关的集中问题，最小候选矩阵如下；此表为实施范围，不代表代码与系数已经冻结：

| 臂 | 共同部分 | 唯一待检验变量 | seed | 训练数 |
|---|---|---|---|---:|
| control | Q05 Region refined 架构＋C＋proposal 0.1 | 保留原路由训练 | 42 | 1 |
| routing | 同 control | 一种经训练／验证诊断确定的路由优化机制 | 42 | 1 |

不同时叠加增大模型、采样重加权、阈值调节和多种路由技巧。优先核实路由梯度、早期选择集中及专家更新情况，再选择单一候选；不得把 Task-ID 的 0.01 系数未经 Region 验证直接称作最优设置。若存在明确实现错误，应先以独立修复验证处理，不能将修 bug 包装成方法收益。

- [x] 形成只引用 train／val 的触发记录与机制说明，明确损失公式、系数、启用层和训练日程；记录 Q05 基础版本及哈希。
- [x] 在新目录准备seed42的2项独立从头训练，验证控制工厂一致性、梯度与恢复行为，并通过真实 512 输入及最重查询批次 GPU 准入。
- [x] 将新协议和检查点选择规则冻结后才加入实际训练队列；沿用全部训练核验后再开放测试的机制。
- [ ] 评价同时要求逐器官分割和错误类型证据。若只改善专家使用而分割无益，结论为未证明性能收益，不继续按测试分数搜索系数。

若 Q05 后不再持续集中，或者集中仅发生于空 proposal 而阳性区域已有合理分工，记录“Q06 不触发／证据不足”，直接进入 Q07。若 Q05 本身出现严重预测退化，先检查数据与实现，不因为缺乏完整诊断就自动展开2项训练。

## 5. Q07：区分条件表达、专家容量与专家分工

**要回答的问题：**Task-ID 的收益是否主要来自任务条件调制；在固定seed42及数据划分下，多个专家相对一个专家或无专家条件网络，是否有质量收益及可接受成本？

先准备 Task-ID 的最小矩阵，避免一次扩成跨架构、宽度、专家数和损失的巨大网格：

| 配置 | 必须相同的条件信息 | 含义 | seed | 训练数 |
|---|---|---|---|---:|
| 无专家条件 U-Net | 同任务 embedding、同四层 FiLM、同逐结构查询与输出 | 保留任务条件，从头训练共享解码器，移除专家路径 | 42 | 1 |
| 1 专家条件模型 | 同上 | 保留一个专家残差，取消“选择哪一个专家”的自由度 | 42 | 1 |
| 9 专家 Task-ID MoE | 同上 | 独立重跑的多专家参照 | 42 | 1 |

该矩阵拟共3项，均使用seed42，是后续待实施范围。9 专家参照不直接复用旧实验数字。9 专家保留既定弱均衡；0／1 专家的相应路由正则须明确记为不适用或常数、无优化作用，不伪装为相同的有效梯度。1 专家的 softmax 权重恒为 1，与9专家 top1 的概率幅值也不同；因此这一对照比较的是完整单专家／多专家设计，不能将所有差异归因为“专家数量”本身。

共同损失、抽样、预算和任务条件一致并不等于容量完全一致。先记录每种模型的总参数、参与一次预测的参数、训练更新数及 FLOPs 估计范围；若结果确有差距，再决定是否需要一个按总参数匹配的加宽条件 U-Net 小对照。匹配宽度须由参数计数规则确定，不按测试分数搜宽度。不同参数匹配方式不能同时保证 FLOPs、显存和时延匹配，须逐项报告。

- [x] 明确 0／1／9 专家三个工厂、相同任务条件入口和查询展开；公共参数按 seed 对齐，记录所有无法对齐的结构差异。
- [x] 无专家路径已通过真实GPU更新、严格恢复和标签忽略检查；新矩阵与源码已冻结，测试结果未决定条件机制。
- [ ] 同设备、相同 PyTorch／CUDA、dtype、分辨率及输入驻留方式测量推理；预热后同步 CUDA，报告重复次数、延迟中位数／P95及峰值显存。
- [ ] 同时测 batch1 和共同可运行批次；Task-ID 分别报告单任务查询与一张图所有请求结构的完整开销，后者包含任务展开与并集组装，不能拿单查询与 Region 一次16通道推理比较。
- [ ] 测量使用固定训练／验证输入、统一推理模式及线程数；有背景 GPU 任务时不宣称是隔离性能基准。GPU 成本测量待正常训练空闲窗口执行。
- [ ] 将seed42各配置质量差与实测成本放在同一表；若1专家或无专家相当，应如实把主要收益归于条件表达或有效容量，降低对复杂路由的主张，不声称跨种子稳定性。

Region 是否也需要少专家配对，由 Q05／条件性 Q06 的验证证据决定，当前不额外预排一整套跨架构矩阵。

## 6. 阶段决策和可支持的结论

| 观察 | 可以作出的决定或表述 | 不应作出的推断 |
|---|---|---|
| Q02／Q05 三种子配对同向，结构 DSC 和距离改善，关键器官错误不增加 | 在当前固定数据划分上存在可重复改善信号 | 三个 seed 等于三次独立临床验证 |
| Q06／Q07 seed42 配对改善 | 在当前固定种子与划分上观察到改善 | 已证明跨种子稳定性或多次独立复现 |
| DSC 改善但漏检或空图误检增加 | 保留两类错误，报告精度取舍，检查 guardrail | 总体分数更高即所有器官更可靠 |
| Q05 后 Region 持续集中且阳性区域也受影响 | 触发 Q06 的单机制准备和协议冻结 | 强制均匀分配一定提升分割 |
| Q05 已缓解集中，或集中与错误无明确联系 | 跳过或暂缓 Q06，优先补 Q07 机制对照 | 为证明设想而继续增加路由技巧 |
| MoE 优于同条件0／1专家且成本可接受 | 支持多专家完整方案的相对收益；容量匹配后可进一步定位机制 | 已训练模型移除专家下降即可证明9专家必要 |
| 仅在阳性、全样本或 best 中某一种口径领先 | 将优势限定到该口径，并列其他口径和 last | 选择有利口径宣布全面优于 AImageLab |

**训练 seed 不是独立患者重复。** 三个种子共享同一划分，用于观察初始化与抽样的训练波动，不能当作交叉验证，也不能把同一患者多张切片或同一 CT 来源当独立患者扩大样本量。若估计患者层面的不确定性，应在有可靠 patient／source ID 的数据域进行成组配对重采样；缺少 ID 时说明限制，不制造患者身份。最终版本固定后再使用预先冻结的新划分或独立数据验证泛化。

历史测试分数已经被用于项目分析；本阶段后续决策产物仅读取验证历史和诊断，不依据测试排行选择获胜配置、调整阈值或挑检查点。这减少进一步选择偏差，但不能把现有测试重新称为完全未触碰的外部验证。
