## 实验规模与入口

五种外部方法各 seed42/43/44，共 **15 项主训练**。每项512×512、80轮、有效查询batch16、每域每轮500张、AdamW 1e-4、weight_decay 1e-4、float32、无增强。查询顺序逐项核对Q01冻结的240份逐轮抽样清单，保持原train/val/test及ignore标签。

实现位于 `unet_moe/external_baselines/`，原始第三方目录保持不变；`vendor/` 同时保存纯网络代码、来源与许可证。共同训练入口为 `python -m unet_moe.external_baseline_suite`，后台控制器为 `scripts/run_external_baselines.py`，冻结入口为 `scripts/prepare_external_baselines.py`。

| 方法 | 保留的核心结构 | 固定方法特有配置 |
|---|---|---|
| Lanzhou-exact-seg-512 | 最终提交的ExactFusedSwinUNet；BN、dilation2/3、固定深监督融合 | 两类logit之差作为单通道logit；physical batch2 |
| AImageLab-zip-seg-512 | ResNet18/CBAM＋FiLM U-Net，完整可学习融合分支和最终IN/LeakyReLU | 9域FiLM，两个分支512；physical batch2 |
| UniverSeg-union-512-retrained | 官方四层64通道CrossBlock；从头训练 | S=8，无支持集集成；physical query batch1，累计16 |
| SMART-seg-512 | 原16个共享query、动态头、双尺度分割、窗口7 | 主BCE+Dice + 0.4×辅助BCE+Dice；physical batch2 |
| MOFO-512-adapted | 原CSWin-S、文本任务提示、动态掩膜头、训练后的pUNet先验 | 9域；BCE+Dice + 0.5域CE + 0.2先验L2；physical batch1 |

BN观察的是实际physical batch，梯度累积只统一查询batch及更新次数，不把它宣称为相同BN统计。各方法保留原有宽度，不能统一套用本项目U-Net的base24。

## 支持集与解剖先验

UniverSeg每张query抽8张同域train支持图，不重复抽同一图，排除query自身以及已知同患者／同体积group。训练支持选择由独立种子1729、训练种子、epoch、抽样位置及query身份确定；验证／测试固定按query身份选择，跨训练种子和检查点保持一致。未知患者ID的数据集只保证已知图像和group隔离，不虚称全面患者隔离。

腹部没有完整标注的整图：并集之外的类别为ignore，不能直接当背景送入UniverSeg。支持集及MOFO先验使用最大完全已知、同时有前景和背景的矩形ROI，短边至少32，且至少保留该图已标注前景的25%。完整标注图保留全图。无合适ROI、全空或缺少已知背景的图不进入支持池／先验池；**这些图仍保留在全部方法的正式查询训练及评价中**。ROI图像双线性、标签最近邻调整为512，逐图记录位置、标签哈希、保留面积及前景比例。

这会改变支持图的视野，腹部先验学习的是可观察的局部结构。它是为了遵守本项目部分标注而公开记录的适配，不能写成原论文完整实验复现。支持池阈值仅依据训练标签可用性设定，没有依据test性能选择。

MOFO使用真实、固定revision的官方CLIP文本编码器生成9个并集任务向量。视觉主干不加载官方分割或ImageNet权重。文本提示、源权重及生成向量分别保存哈希。

MOFO另有 **3 项先验训练**，每seed独立80轮、每域每轮500个train掩膜、batch16、lr1e-4。其多尺度对比项使用完整有效batch的正负对，采用两遍前向的精确梯度缓存降低显存。主分割训练只接受相应seed真正完成的先验；先验参数冻结，连续预测输入仍有梯度。

UniverSeg每项主训练额外抽取288万张支持图；MOFO每seed额外抽取36万份先验掩膜且每份两遍前向。这些成本单列，不能声称五种方法总计算预算完全相同。

## 队列顺序与准入

前置顺序为 **Q01全部训练和测试完成 → 三指标补评结束且没有失败 → Q04**；前两项已经完成。Q02也已独立实现、冻结并接在Q04之后，其主损失已按完整Q01验证结果确定。Q04使用相同GPU文件锁与双卡调度。

Q04内部包含必需的GPU准入阶段：每种结构在真实512图像上完成两次有效batch16优化更新，严格保存／加载模型、optimizer、RNG，并核验恢复后预测；根据实际峰值显存加余量决定能否派发。**CPU功能验证不等于GPU显存预检通过。** MOFO先完成seed42先验才做包含真实先验的主模型预检，其余seed也必须先完成各自先验。

模型、数据清单、逐轮抽样、支持ROI、依赖版本及源码快照冻结到独立运行目录。后台进程使用快照，工作区的后续编辑不会改变正在跑的实验。失败保存日志及失败记录，不把失败当完成，不自动降分辨率、改结构或减batch。修复后重启控制器需显式 `--retry-failed`；协议改变需另开新实验。

所有15项主训练完成及检查点选择固定后，才打开本矩阵test。每项同时评价 `best` 与固定epoch80的 `last`，生成逐图、逐域及腹部CT分层的 DSC (%)、HD95 (pixel)、ASSD (pixel)。单侧空掩膜距离为 `hypot(511,511)`；全样本、阳性和GT边界可定义子集分别汇总，距离不可定义保留NA及覆盖数量。
