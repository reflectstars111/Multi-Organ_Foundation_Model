运行与监测见[Q04执行说明](Q04_EXECUTION_20261013.md)。CPU端到端功能验证已完成；GPU两次有效batch16更新与显存检查是队列的强制准入步骤，未执行前不标记为已通过。MOFO三个seed的80轮先验是另列的训练阶段，不能把CPU验证用的一轮先验当正式权重。

用户已明确选择：MOFO、UUSIC 2025 前三名、UniverSeg 作为外部 baseline；使用现有划分、512×512、80轮、seed 42/43/44 重新训练；共同主对照为**所有已标注结构的前景并集**。各方法保留自身条件机制和核心结构，官方／比赛分割权重不作为主对照初始化。逐器官扩展另列，不纳入本次15项主训练。

“前三名”指 UUSIC 2025 **分类与分割联合挑战赛的总体排名**，不能写成分割单项前三名。来源：[组织者发布页](https://zenodo.org/records/21807962)。这些方法在本项目重训后应使用上表适配名称，不能把结果写成其原比赛成绩或原论文完整复现。

本项目主表由上述5种外部方法，加现有单通道共享U-Net、Task-ID MoE、Region MoE组成。后两者保留结构监督训练和原输出，评价时按已有规则求可评价结构的并集；不把它们改成单通道模型。16通道U-Net继续作为附加对照。

## 2. 已确认的数据、训练与评价条件

| 项目 | 约定 |
|---|---|
| 新增主训练 | 5方法 × 3种子 = **15项**；MOFO先验等准备阶段另外计数 |
| 数据来源 | 沿用Q01冻结的 `paper5/trainmore_v6/ct7_2` 数据及划分，不使用外部比赛包替换 |
| 记录指纹 | `f621896f10234777d3067a019d96a7cb1dae3b6add305bca32815298744315e0` |
| 划分与训练种子 | split seed=42；training seeds=42/43/44 |
| 图像 | 512×512；灰度模型使用1通道，RGB模型复制为3通道，所有归一化变换写入各方法配置 |
| 预算 | 80轮；每域每轮500张查询图像，9域4500张；有效查询batch16、每轮282次更新、每次训练360000个查询图像抽样 |
| 共同优化配置 | AdamW，lr=1e-4，weight_decay=1e-4，恒定学习率，无图像增强；物理batch及累积需显存预检后记录 |
| 模型容量 | 保留各自网络宽度、层数和原有计算分支；`base=24`、`experts=9`不是可套用到全部方法的参数 |
| 分割目标 | 使用现有 `UnionDataset` 的已标注结构并集和ignore规则，不生成新数据划分 |
| 指标 | DSC (%)、HD95 (pixel)、ASSD (pixel)，都在512评价网格计算；单侧空掩膜用 `hypot(511,511)` 惩罚 |
| 统计 | 逐图、逐域、9域宏平均、腹部及CT来源分层；保留全样本、阳性和GT边界可定义子集及数量 |
| 防止错误解释 | 参数量、峰值显存、训练时间、支持集读图次数、额外先验阶段均单列；不声称总计算量完全相同 |

现有数据清单为6737/1007/1618张 train/val/test 图像。腹部仍只合并肝、肾、血管、胆囊、脾；其余约定的未纳入类别和源ignore像素为-1。AUL只有肿块标注时背景仍为未知，不能当作背景训练。规则来源：[80轮协议](UNIFIED_80_512.md)、[并集定义](SHARED_UNION_VS_MOE.md)、[三指标补评](MEDICAL_METRICS_REEVALUATION.md)。

**检查点口径**：保留验证集九域阳性并集DSC选出的 `best` 以及固定第80轮的 `last`。现有MoE原始best依据16结构指标选择，因此新增一个所有方法都使用epoch80的固定轮次对照表，用于排除选优指标不同的影响；原best结果保留，明确各方法的选择规则，不追溯改写旧协议。

完整15项主训练及选优完成后才开放本矩阵的test。配置、辅助损失、支持集策略均只在train/val上决定，不根据已知测试结果换方案。当前test已有历史分析，不称为从未接触的外部测试。

## 3. 初始源码审查与适配要求（2026-10-12历史依据）

以下记录登记时的缺口和设计约束，不代表当前仍未实现。已完成实现见 [MOFO](baselines/MOFO_IMPLEMENTATION.md)、[SMART](baselines/SMART_IMPLEMENTATION.md)、[AImageLab/Lanzhou](baselines/FINALISTS_IMPLEMENTATION.md)、[UniverSeg](baselines/UNIVERSEG_IMPLEMENTATION.md)。腹部整图无完整二值标签的问题已用明确的有效ROI支持／先验策略处理，query仍全图；阈值、保留比例与限制见执行说明。

### MOFO：保留文本语义和解剖先验

官方源码：`relate_baseline/多器官超声基础模型 (MOFO)`，本地提交 `c5076f087ae68bfb7ba19d976def2dcd5224f1c8`。[完整审查与源码行号](baselines/MOFO_SOURCE_AUDIT.md)。

- 224输入、提示特征7×7和CSWin窗口7均有硬编码。512需要动态提示网格以及正确的窗口补齐、有效token掩码和输出裁剪，不能只改resize。
- 9域并集任务保持每图一个任务标签，避免把同一腹部图五个器官强行作为互斥分类标签。已知域是额外条件信息，报表须显示。
- 原脚本先把预测硬阈值化再计算先验约束，导致该项对分割网络不产生梯度。重训练必须使用连续概率，冻结先验参数但保留其输入梯度，并做梯度验证。
- 本地缺少提示编码与先验权重及其生成／预训练入口；需要依据论文补齐，先验只能使用train掩膜。未知像素不能直接编码成真实背景；需选用标签完整的先验样本或实现明确的有效区域策略。
- 不能用随机先验网络、随机文本向量或删除先验来冒充完整MOFO。视觉主干初始化与固定CLIP文本语义来源分别记录；“重新训练”不意味着擅自丢弃原方法语义组件。
- 原代码损失与论文有差异，正式冻结时逐项列出采用的公式、系数、归约和先验阶段预算。MOFO额外训练成本不能藏在80轮分割预算里。

### SMART：共享query不等于器官输出通道

[完整审查](baselines/SMART_SOURCE_AUDIT.md)。保留16个可学习query、动态卷积及双尺度分割。原query用于跨分支特征交互，并不代表16个器官。

512特征网格无法整除原窗口7，必须实现正确的padding、shift mask和裁剪。保留分类模块，但当前医学数据没有比赛完整2/4类诊断标签，不能将数据域标签冒充诊断标注。主方法因此明确命名为 **SMART分割重训适配**；其双尺度分割损失在训练前冻结，不能声称复现了原联合分类训练。

### AImageLab：保留可学习融合分支

[完整审查](baselines/AIMAGELAB_LANZHOU_SOURCE_AUDIT.md)。原分割输入已是512；9域FiLM条件与输出并集按上述主协议适配。

发布权重中的融合参数 `alpha=0`，但从头训练时它可以学习，因此主模型保留完整融合结构。原最终输出层的InstanceNorm/LeakyReLU也不擅自删掉。比赛入口 `model.py` 在导入时就会执行目录与推理操作，应隔离封装纯网络模块，不直接导入该入口。本轮两个分支都接收512图像，分别保留明确的强度归一化；相较原提交分类分支256输入，这是已声明的分辨率协议适配，需计入显存预检。

### Lanzhou：使用最终提交结构

[完整审查](baselines/AIMAGELAB_LANZHOU_SOURCE_AUDIT.md)。采用 `exact_model.py` 的BN、dilation2/3、普通特征增强、固定深监督融合；不能用 `train_fused_swin_unet.py` 所导入的GN/ASPP/注意力门控开发模型替代。

原模型为无条件背景／前景输出，直接使用并集标签。评价时使用 `z_fg-z_bg` 的sigmoid，与原双类softmax前景概率等价。补写正确的训练加载器，不能继承现有开发脚本中图像与mask增强不配对、train/val共享transform及缓存首轮DataLoader等问题。

### UniverSeg：补齐完整的支持集训练

官方源码已保存到 `relate_baseline/UniverSeg`，提交 `833a0c34c65e38d675e21bd48ddec6797cc03259`。来源：[官方仓库](https://github.com/JJGO/UniverSeg)。不加载官方预训练分割权重。

保留官方 `[64,64,64,64]` CrossBlock配置，输入查询图像 `[B,1,512,512]`、支持图像及标签 `[B,S,1,512,512]`，输出并集logit `[B,1,512,512]`。原官方使用说明为128，512需要实际前反向和显存验证。

支持集只来自train、与query属于同一并集任务；排除相同图像以及可识别的同患者／同体积来源。支持掩膜接口只有二值标签，没有ignore通道，所以不能将-1直接改0；必须统计并冻结标签完整的可用支持池，某域数量不足时明确处理，不能跨域借用或偷偷重复。

训练种子和支持集选择种子分别记录。支持大小、验证／测试固定支持池、是否支持集集成是独立超参，在预检和验证阶段冻结；不能根据test挑最优支持集。支持图像曝光和计算量额外统计，不与“16张查询图像”的batch概念混淆。
