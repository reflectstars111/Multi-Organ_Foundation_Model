### 实验矩阵与固定条件

计划覆盖多头共享 U-Net（`shared`，16 通道）、Task-ID MoE、Region MoE，各使用 seed 42/43/44。每个模型、每个种子内进行三组配对，共 **3 模型 × 3 实验组 × 3 种子 = 27 次从头训练**。单通道前景并集 U-Net 没有独立器官输出，不纳入这组逐器官损失消融。

| 实验组 | 损失变化 | 配对比较 |
|---|---|---|
| A：`image_mean` | 现有 masked BCE + soft Dice，先对每图有效结构平均，再对图像平均 | 从头训练的原损失对照 |
| B：`organ_exposure` | 在 A 上，按训练采样器下的器官监督曝光校正通道损失系数 | B−A：仅检验器官曝光校正 |
| C：`organ_exposure_fg_bg` | 在 B 上，加入有上限的前景／背景加权，并明确阳性图和空标签图的处理 | C−B：检验额外前景／背景加权 |

### 权重定义及冻结方案

设图像 i 有 K_i 个有效标注通道，I_ic 表示通道 c 有有效标注，单通道损失为 l_ic。A 组为 `mean_i[sum_c(I_ic * l_ic) / K_i]`。B 组定义：

```text
s_c = E_训练采样器[I_ic / K_i]
w_c = 1 / (16 * s_c)
L_B = mean_i[sum_c(I_ic * w_c * l_ic) / K_i]
```

期望按实际域均衡采样概率计算，只使用训练集。保留 K_i 分母，不能改成每图权重之和，否则同图五个腹部通道的统一增权会被抵消。该定义令每个结构的期望损失系数为 1/16，并保持总体期望系数之和为 1；不保证梯度范数相等。按当前九域等量采样、腹部每图五通道有效的条件，腹部通道系数从 1/45 校正至 1/16，对应乘数 2.8125；正式权重仍以实际有效掩膜统计为准。

C组已冻结为仅对阳性图通道的BCE加权：q=(训练阳性图前景像素+1)/(训练阳性图有效像素+2)，r=clip(sqrt((1-q)/q),1,4)，z=1+(r-1)q；前景乘r/z、背景乘1/z。空标签图BCE保持原样，Dice保持原样，再应用B组器官系数。实际腹部B系数均为2.8125。器官“大小”指有效标注区域内的前景像素占比，不解释为物理体积；未叠加逆数据集大小或逆阳性频率。完整数值、护栏及15张固定探针见[运行协议](Q01_ORGAN_WEIGHTED_512.md)。

所有权重统计来自 train；如需筛选 C 组超参，只能使用另行登记的 train/val 试验，并在本矩阵启动前冻结。不得逐种子选择最优权重或用 test 调参。公式未冻结前不将 C 组标记为可运行。
